# Instructions

## Overview
This calculator helps you plan RuneScape training by comparing current progress against goals and method XP rates.

## Profiles
- Use the `Profile` dropdown to switch characters.
- Click `New` to create a profile.
- Click `Delete` to remove the selected profile (`default` cannot be deleted).
- Tip: use your RuneScape username as profile name for easier high-score importing.

## RS3 High Scores
- Click `Import RS3 High Scores` to pull XP from RS3 high scores into the active profile.
- Import updates current XP/level data for skills found in the feed.

## Skill Grid
- Click a skill to open its details.
- Drag and drop skills to reorder the grid.
- Click `Reset` in the Skills panel header to restore default layout order.
- Each skill tile shows:
  - Skill name
  - `current level / max level`
  - current XP
  - mode badge (`[GOAL]` or `[NEXT]`)
  - progress bar

## Virtual Levels
- Toggle `Virtual levels` in the top-right to switch display mode:
  - On: virtual max level display
  - Off: real max level display

## Current / Goal Inputs
Each skill supports:
- Current point
- Goal start
- Goal end

For each point you can choose:
- `Level`
- `XP`

Use `Use Current as Goal Start` to quickly copy current values into goal start.

## Goal Tracking
- Enable `Goal tracking` in the Current card to activate goal cards.
- When enabled, statistics show:
  - goal start level
  - goal end level
  - XP needed
  - goal progress text + bar

## Methods
- Method rows are color-coded:
  - Green: can do now
  - Yellow: can do within goal range
  - No highlight: outside current/goal range
- Method tabs are generated from `Type:` values.
- Method tabs can be reordered per skill (saved in profile).

## Boosts
- Enable/disable boosts with checkboxes.
- Boosts change effective XP/action and actions needed in methods table.

## Data Management
- `Export Data`: downloads your saved app data as JSON backup.
- `Import Data`: restores backup JSON (with preview and overwrite confirmation).
- `Reset All Data`: clears all app data for this site.

## Reset Skill Settings
- `Reset Skill Settings` resets selected skill settings except:
  - current XP
  - current level/input mode state

## Report Issues
- Use `Report Issue` in the footer to open bug reporting.
